# PROVENANCE — how the `consolidated` branch was assembled

`consolidated` forks from `codex/paper-final-runs` (the manuscript branch; `master` is its ancestor) and carries, in one tree, every file the 69 experiment branches produced. Nothing was re-run to build it; every number in `results/` is the number the originating branch banked. This file records where each part came from and every policy decision, so the branch can be audited without opening the others.

- `src/eeg_scad/` — byte-identical to `codex/rgcc-eog-v44` @ `f15335d` (145 modules). - `src/eeg_cgdr/`, `src/eeg_cspd/`, `saddpm/` — the PAPER branch versions are authoritative (they produced `results/cgdr`, `results/paper_final`). Lineage additions that did not exist in the paper branch were added; on the files both sides changed, see §3.

## 8. History

After the tree was committed, every lineage tip was merged with `git merge -s ours --no-ff` (tree unchanged), so all 69 branches are ancestors of `consolidated` (`git branch --merged consolidated`) and `git log` from here reaches every experiment's commits. The content merge itself is the explicit vendoring described above, not those merge commits.
