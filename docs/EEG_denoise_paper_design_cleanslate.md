## 一、核心转变：从"旅程"到"演绎"

探索的顺序是归纳的（试 X 败、试 Y 成）；从零设计的论文是**演绎的**：形式化设定 → 信息账户 → 方法作为账户的收款装置 → 测量作为验证 → 负结果作为**设计公理**而非道歉。同一批事实,组织成"这个设计为什么必然长这样"。

## 二、论题与标题

**论题**（敌意评审修正后的措辞,规避了"收取全部增益"与账本 36.9% 的自相矛盾）：

> 在跨被试 EEG 去噪中,可支出的被试信息存在于伪迹耦合算子而非神经先验——条件化天花板在密集 montage 上以三种独立方式测得为零,且并非规模不足所致——因此方法是一个被试不可知的 population 扩散先验,其上覆盖一层校准估计、可靠性门控的算子层,由两条按 montage 选择的通道收取实测增益（运行时参考锚：密封确认 +0.1537, 7/8, 复现开发集 +0.143, 15/15；算子传输：零训练 +0.016/+0.018）,以精确 population 旁路为认证下限、以弃权为共享的安全与隐私机制。

**标题**（主选）：*Calibration, Not Conditioning: Subject-Aware EEG Denoising by a Certified Operator Layer over a Population Diffusion Prior*
（"Personalize the corruption, not the prior" 作全文复现口号而非标题；备选见面板 D1/D3。）

## 三、贡献排序（编辑裁定；摘要中倒序呈现——摘要卖交付物,引言建账户）

- **C1 通道-天花板矩阵与空条件化账户**（十年后被引用的那条）：三种独立方式杀死条件化通道（嵌入 +0.0063 CI 跨零；oracle-trained −0.051 天花板低于地板；权重空间 LoRA −0.020），规模对手解释被 n=8 交叉实验拒绝——把领域实践从 identity embedding 转向。
- **C2 被选择的系统与密封确认增益**：+0.1537 [+0.0725,+0.2504] 7/8,复现开发集 +0.143 15/15——账户"能付款"的构造性证明,也是论文最强的证据卫生样本。
- **C3 认证门 + 不可验证性 + 隐私**：精确逐位旁路、错误捐赠者中和（−0.000223 vs 未门控 +0.654）、线性伤害界（斜率 1.390）、"漂移击败一切算子特征身份检验"（漂移校准阈下检出率仅 20%）、零链接隐私阶跃（λ=0 恰为 0.500）。
- **C4 残差账本**：0.38694 跨度闭合到 0.9% 未归因、转化带 0.37–0.50——作为领域应当采纳的核算标准呈现。

## 四、形式化设定（S3,理论章）

`y = x + C_s(t)·e(t) + ε`,`C_s = C̄ + Δ_s + δ_s(t)`。三条候选个性化通道,每条给**操作性预算**（干预实测的 oracle 天花板,明说不是不可计算的互信息）：

- **B_cond（条件化先验通道）≈ 0**（三重测量 + 规模对手拒绝）——"空账户";
- **B_anchor（实现货币）**：运行时参考通道逐窗测得 e(t)——减除天花板 +0.312,可部署 +0.143,转化带 0.37–0.50;
- **B_transport（几何货币）**：稀疏 montage 上的 Δ_s——天花板 +0.04–0.11,零训练可部署 +0.016/+0.018（≈半天花板,与锚通道转化带一致）。

六条**实测规律**（编辑修正：不用 "Proposition N" 编号以免抬高证据门槛,称 measured regularities,逐条标注证据等级）：空通道 / 可靠性≠身份（四重复现）/ 线性伤害律 + 坏锚不如无锚 / 冗余律（方差累积,回溯拟合 0.596 与 −0.0072）/ 眼动特异性边界（运动算子无被试性）/ 校准不可替代性（RLS 全时程落败）。

**理论章内嵌诚实台账**：定量的（0.9% 闭合、转化带、伤害斜率、D_deb/τ²=2.0 落在预测带）与开放的（B_cond 为何为零——幸存但未从头推导；门是拟合的非推导的,λ 预测 0.50 vs 实测 0.89；未交付份额非漂移、归因未定,类型化算子误设为首要嫌疑；先验塌缩的 U-ratio 1.40 悖论,病因未知）**并列明示**。

## 五、系统（S4,方法章——每个组件收取一种货币,每个"没有"对应一个测得的零）

1. **Population 扩散先验,刻意被试不可知**——score 网络无任何被试输入（无嵌入、无条件化通道、无逐被试权重）,理由=C1;时长随机化门控训练（0.632→0.526,+17%,惠及所有臂）;分面板先验（池化先验塌缩事实的设计回应）;诚实定位:确定性孪生在点估计上领先 +0.0217,全文 competitive 措辞;扩散的挣钱处在 UQ（CRPS/RC-AUC 首胜确定性集成）。
2. **闭式被试算子层**——专用校准会话（RLS 事实=不可替代）产出 Ĉ_s 与 EB 后验（λ̂≈0.88–0.92,近二值）,后验显式保留并传播（K-chain）。
3. **通道 A（锚）**——montage 支持参考导联时,e(t) 经校准算子进入似然;**回落是无锚而非 population 锚**（0.574 vs 0.651 事实）。承载论文头条。
4. **通道 T（传输）**——稀疏 montage 上的坐标对齐,零训练解析式;κ 守卫 + split-half 弃权。
5. **按 montage 选择,永不堆叠**（冗余律）;**精确旁路**（λ=0 逐位=population,fail-closed 是构造性质）;**UQ 头**（算子后验 K-chain）。
6. 章末"**刻意缺席清单**"（D1 器官）:被排除的每个组件与排除它的那个数字。

**部署分类学表**（TAAS 最易读对象）:montage 密度 × 运行时参考可得性 → 启用通道;含界外格（57ch 短支撑 −8.6/−11.5 印在表里）与 100% 弃权格。

## 八、EEGEyeNet 计划（S10——"showcase never"铁律:MobileBCI 密封 +0.1537 是封顶石,EEGEyeNet 永不承重）

按单位工作量提升排序（编辑裁定）:
1. **判定器/仪器块**（CPU 级）:真 VEOG 的 A4 行（替换 1.7673 轴受限界）、类型标签（κ 检验）、事件级 oracle、readout 重定界——四个悬空账行一次关闭,价值不依赖任何增益复现;
2. **类型化算子族检验**（唯一真正新科学）:type-indexed 族 vs 静态族,主端点=0.37–0.50 缺口的回收比例;零结果也把 family-final 升级为 reference-verified;
3. **第二次密封确认**（杀 n=8 异议;隐藏成本:129ch 新面板需训练分面板先验——真正的 GPU 项）;
4. **356 被试规模条件化探针**（~30 GPU-h:被拒的阈值账户预测 ~300 被试,356 恰好跨在上面——对空通道主张的最后一个异议做廉价决定性封印）;
5. showcase 角色:**永不**。
全部预注册、全部 additive、通过前不入摘要。
