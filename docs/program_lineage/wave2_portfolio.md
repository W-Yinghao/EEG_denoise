## 一、统一机制账户（"漂移算子、删失先验、模式移位经济"）

一个生成模型解释 digest 里的所有数字：`y = x + C_s(t)·e(t) + ε`，其中 `C_s(t) = C̄ + Δ_s + δ_s(t)`（population 均值 + 结构化的被试偏移 τ²[粗方向大、身份细方向小] + 会话内漂移 D）。五条原理：

1. **信息预算与模式移位原理**：被试通道只在移动 p(x|·) 后验模式时才有价值。预算分两种货币——**B_realization**（每窗伪迹实现 e(t)，EEG 单独不可辨识但参考通道可直接测量）与 **B_operator|y**（看过 y 后对混合算子的剩余不确定性：密集 montage 上≈0 [conditioning 天花板 +0.006]，稀疏 montage 上可观 [transport 天花板 +0.04–0.11]）。V44 的 +0.143 不是条件化终于成功——是 B_realization 被兑现（测得的 query EOG 是任何静态被试描述子都载不动的每窗信息，算子精度是乘数不是载荷）。
2. **通道演算**：静态学习描述子只载 B_operator|y 且缴纳按被试数定的摊销税（阈下 → population 映射是风险最优 → 三种死法：可忽略→精确零 [V42R]；训练强制→方差主导→指错方向 [S1.5 −0.051、S2b fold 符号翻转]；逐被试权重→零价值减干扰 [LoRA −0.020]）。闭式物理通道样本复杂度 ~10² 参数/120 秒、零摊销税，交付 ρ_eff × 天花板。
3. **半转化律与 D≈τ² 一致性**（⚠ 敌意评审修正后）：交付/天花板的诚实区间是 **0.3–0.5**（非 0.4–0.5——V44 与 W3 的 oracle 残差语义不一致，加性/总量两种读法要统一），推出 **D ∈ [τ², 2.4τ²]**（D≈τ² 是乐观端点，非解出的方程）。它统一解释：所有权验证死（own/wrong 距离 √3:1 重叠 → AUC 0.70–0.80 带，实测 0.717–0.782——但此回溯含未声明的低维假设，是一致性检查非确认）、效用活（只需支持估计在粗方向胜 C̄）、隐私阶跃（support↔support 链接无漂移损耗）。**λ/ρ 门以 W 为阈——与身份正交——所以估得准的错误算子必然穿门（4 次复现是定理不是 bug）**。
4. **符号误差与流形位移**（为什么坏的被试估计比没有更糟）：物理通道在测量空间做减法，部分/错误减除把 ON-manifold 损坏变成 OFF-manifold 结构化残差 `(C_s−Ĉ)e`——population 模型没见过后者。统一解释 NO_A0<POP 锚、GAUGE-NULL 谱、以及 **M13R 先验塌缩**（按低 EOG 代理选"干净"窗 = 删失真实干净 U° 能量 → 先验干净模式沿 U° 位移 → 后验过扣——**删失即模式位移，ambient/损坏建模是结构性解药**）。学习通道吸收自身误差（零后负），物理通道同时转化信息与误差——所以认证门+弃权架构不是可选项。
5. **冗余、依赖与二阶矩**：V43-S2 重训练模型 = 账户最干净的确认——**load-bearing without being information-bearing**（可靠性契约下网络会读通道，但内容对 y 冗余：对的状态什么都不变、错的状态什么都变）。[这是实测的 functional-reliance-without-information——与你的 CMI 研究线直接桥接。]

**敌意评审的三处必修**：半转化律残差语义统一（0.3–0.5）；P10 相干性守卫与原理 4 自相矛盾（会放过近错捐赠者——被 DT-Gibbs 的似然路由取代，不单独跑）；transport 残差被双重记账（漂移 vs 先验质量——**P1 同块重放（CPU）必须最先跑**，它同时给 OPERA-E2 和 DT-Gibbs 的奖金定价）。

## 二、四设计裁决（两评审收敛：D2 > D4 > D3 > D1）

| 设计 | 一句话 | P(正标题) | 裁决 |
|---|---|---|---|
| **D2 DT-Gibbs**（漂移拴系半盲联合后验） | 校准 EB 后验初始化、图集漂移分布做护栏、激励门控、混合逃逸到 population 的 Gibbs 算子-信号交替，全部推理级 | ≥1 腿 0.60–0.65 | **第一优先**：唯一同时升级两条已确认腿 + 修复 V44 唯一失败端点（wrong-gated +0.038→≤0.005）的设计；$0→10→80 GPU-h;敌意修正：C-step 偏置方向可能反号（不纯先验→Ĉ 膨胀→过扣，与 M13R 同向）→ G1 泄漏门必须双侧等价界；GB-1 诚实预期 +0.03–0.08 非 +0.12 |
| **D4 THRESH**（ICL 阈值定律合成检验） | 图集校准的任务先验 + 模型规模阶梯 → 转变曲线 + 条件伤害签名（oracle-trained 的"有害而非平坦"是新签名） | 全包 0.40–0.45，某分支有信息 ~0.85–0.90 | **第二**：T0+T1a（~12 GPU-h）在所有分支买下旗舰 Discussion 机制节；G-C 门用 M0 实测天花板（+0.0063，CI 顶 +0.0197<+0.02）**把完整 TIDE 建造锁死**；各向异性伤害重推导必须在 T0 纸面完成 |
| **D3 MOKA**（运动/IMU 物理通道） | IMU→EEG 运动学算子锚 + 静默逐位恒等地板，framework 跨伪迹家族泛化检验 | 0.15–0.20（关键 M-B crux 真 50/50 且零 GPU） | **第三**：第三篇论文的 modal 创始者；步骤零 = 服务器核实 v4/v5 IMU 数据存在 + 拉原始关闭措辞；错配伤害对运动比 EOG 更危险（NO_A0 类比臂从第一个 GPU 臂就要在） |
| **D1 OPERA**（ambient/EM 删失-free 先验） | 经校准算子过程的去卷积训练，零干净窗选择——C4 关闭措辞邀请的重开 | 0.15–0.20（A1 双分离 0.6，单独可发表） | **第四但资助便宜臂**：A0→A1（≤25 GPU-h）是 finding-7 的体外演示；e 的外生性是中心识别假设→A0 硬门；A3 规模（250–450）押后至 A2 通过 **且** P1 重放裁决归因 |

**确认的 kill**：完整 TIDE 建造（G-C 锁死）、OSCAR（含 BCI2b 残余）、静态算子特征所有权、秩截断白化、P10 相干性守卫单独实验。

## 三、组合的结构性质

- 四个不同水库、近零相关失败、**结构上不可能反伤旗舰**；
- P(≥1 新正标题) ≈ 0.75–0.85；**P(旗舰被强化) ≈ 1.0**（理论脊柱、带修复行、finding-7 演示、Discussion 机制节在每个分支都是交付物）；
- 真实约束是**写作带宽不是算力**：设计上至多两个设计活过 cheap-kill；
- **封存资产碰撞是全波最重要的排程约束**：M35 拥有 MobileBCI-8 开封（不为任何人延迟）；DT-Gibbs G2 若赶在开封前冻结则搭同一次开封，否则改道 SHU Day-4/5;PhysioMotion-10 留给 MOKA M-F;BrainID Day-200 留给跨天漂移证伪——全部先写进**封存支出账本**再动。

## 四、执行序（周为工作序）

- **W0–2**（纯 CPU，与 M35 并行）：封存账本 → 共享图集/漂移层（一次建成 = G0 + T0 输入 + MOKA 脚手架 + P2 台账 [修正语义]）→ P1 同块重放 + P7 剂量响应 + **漂移加宽 W4 重放**（从 N(C̄,Σ⊕Σ_drift) 抽样、无 Gibbs——把 DT-Gibbs 的 UQ 腿与其风险解耦，Gibbs 死了也能修旗舰带宽行）→ MOKA M-A/M-B → OPERA A0 → **全部 Tier-2 预注册冻结**。
- **W2–4**（~50–70 GPU-h）：DT-Gibbs G1（双侧泄漏门）、OPERA A1、THRESH T1a。三个 kill 点全部便宜。
- **W4–8**（有门槛，~150–260）：**G2 最优先**（必须赶在 MobileBCI-8 开封前裁决）；T1b 视第二论文意愿；A2/M-C 按门。
- **W8–12**：THRESH T2 在旗舰 Discussion 冻结前完成；旗舰按期冻结（Tier-3 结果按规则归第三篇论文）。
- **W12+**：至多一个 scale-up 毕业（MOKA modal 或 OPERA at scale）。
- 预算：Tier-1 ≈ 40–60 GPU-h；全波至完整裁决 ≈ 250–400；Tier-3（300–600）严格在门后。
