## 〇、一句话

IRIS 是对 (清洁信号 x, 算子 C, 漂移 δ) 的**完全边缘化贝叶斯推理**,其似然由**类型化富参考算子族**（眼动状态驱动）承载、先验由**可微生物物理前向模型 + 356 被试图集**结构化、门由**似然协方差膨胀**连续实现——被试永远只活在似然里,score 网络保持被试盲;而且**现有已认证系统是它的精确子模型**,因此结构性地不可能更差。

组合 P(在 ≥1 个预注册公平读数上击败 +0.143/+0.1537) ≈ **0.55–0.60**;P(过门后劣于现系统) **< 0.10**。

## 一、五层架构

**1. 似然/族层**（OTTO 核 + CORNEA 核）:
`y_t = x_t + [G_phys(θ) + Δ_typed]·ψ(t) + ε_t`
- 类型化驱动 ψ(t) = {注视/CRP 项, 眼睑/眨眼核（逐事件潜幅度）, 扫视尖峰列车, (瞳孔)}——**伪迹类型由源动力学区分,无分类器**(眨眼走眼睑核、垂直扫视走 CRP 旋转——同一几何、不同驱动,这是静态线性 EOG 族无法表达的 rider 交互);
- Class G(有眼动仪): EyeLink 直接供 ψ;Class E(仅 EOG): 经同一前向模型用 switching-KF 反演驱动;Class Z: population 路线;
- **伪 EOG 列保留 → 现系统 46×2 静态族是精确子模型**——组合在结构上不可能差于已认证的东西(下限已密封确认);
- G_phys(θ): 可微模板 BEM 眼动前向模型,~12 个物理参数(CRP 力矩、朝向偏置、眼睑增益、扫视尖峰增益、κ_skull)——眼睛位置解剖学已知;Δ_typed: 秩约束的分类型经验残差,吸收头模型失配(物理供 population 流形,经验残差兜底,EB 在两者间按被试与数据量取点)。

**2. 先验层**: θ ~ N(θ̄, T)(356 被试 EM 估计的物理 population 先验);Δ 按类型 EB 收缩向图集 {B̄_k, τ_k², W_k}(现成的去偏差矩机器);**算子级混合成分 {被试后验, θ̄ 物理模板, 转运捐赠者(稀疏 montage,κ 映射进先验宽度), null/NO_A0}**——回落梯直接写进概率模型。

**3. 推理层**（OMEGA 核,领衔）: (θ, Δ, drift) 在引导反向扩散内与 DET 孪生内的 Rao-Blackwell 化边缘化;**门 = 协方差膨胀** `S = σ²I + M(Σ_θ+Σ_Δ+Σ_drift)Mᵀ`,逐方向、逐窗——校准差时修正**连续**衰减向 population 路线,**二值弃权悬崖(账本最大损失行 35.4%,其中 91% 集中在 1.92/cell 的弃权事件)结构性消失**;逐窗边际证据做责任路由(对漂移边际化,漂移致宽而非误报);硬弃权仅存于后验预测 fail-closed 检查与 F10 隐私端点(π₀=1 ≡ λ=0,精确零链接);伤害证书: E[harm] ≤ 1.390 × E[后验位移](线性伤害律),带预注册 ε 钳位。

**4. 估计器层**: 标准支持下精确类型化 WLS → Laplace 后验(闭式优先——F5 元教训:学习组件对闭式四连败);CAPO 的 NPE **仅**准入 t ≤ 30 s 校准与漂移预测头,各自背着"击败闭式"的 kill;SBC 作有效性仪器。漂移: 3 维物理态 Kalman({γ_L, γ_R, β})+ 类型成分伪漂移的结构性移除,默认 OFF,过 F5 门才 ON。

**5. 去噪/UQ/montage 层**: 冻结 population 扩散检查点 + 一个新的被试盲 129ch EEGEyeNet 模型;DET 孪生承载全部点主张(F8);K-chain 带算子后验重抽样承载 UQ(**物理可解释的带——CRP 增益、眼睑增益的置信带**);conformal 包装。montage: 物理门通过处用前向求值渲染任意电极(**κ≈4600 病理结构性删除**——不再有任何协方差白化),否则有效性门控的样条渲染。

## 三、评审裁决要点

- **OMEGA 领衔的三条理由**(物理评审): 唯一在**现基准面板、同参考、同先验**上作战的核心(赢=纯机制赢,无可比性星号);唯一主导失败模式是**平局**(后验变宽→population 路线)而非输;天然宿主——其它三核都是它的先验结构/似然列/估计器,反向组合都不成立。
- **CORNEA 物理风险**(诚实降级): 模板 BEM 在眶周恰是模板物理最差处(薄骨、孔道、鼻窦)——与杀死所有 canonical 对象的失败类同类;眼睑是滑动分流不是偶极子(最大伪迹类、最差建模源)。**降为门控的先验均值假设**(S0b 门: G(θ̂) 须解释自由拟合 ≥0.75× 的额部伪迹方差),死了就退化为类型化经验图集——方法照常运转。
- **OTTO 参考丰富度警告**: EEGEyeNet 上的胜利部分来自参考而非机制——**两种读数都预注册**(same-reference: 现系统也给眼动驱动;native-reference: 部署公平)。λ 波/前扫视神经活动的外生性风险由硬保留门(≥0.84)承载。**注视流本身是生物特征——新隐私面**,在任何隐私语言前必须探测。
- **CAPO 降为门控组件**: 银标签循环性(真实数据监督最多教会它模仿长支持 ridge)+ F5 四连败先例——作为领衔死刑,作为 10–30 s 短校准前端(独家部署红利)廉价可测。

```

     门:眨眼正向匹配中位 ≥0.70[Tobii 死于 0.24 的那道门]+ 反向抬升 CI-low>0)

     GO: 弃权 cell 损失回收 ≥30% / 逐 cell 永不劣于 NO_A0 / 错误捐赠者伤害 ≤+0.005
```

## 五、与论文设计的关系

IRIS 成为《Calibration, Not Conditioning》框架下的**方法主体**;现系统降格为精确子模型/首要消融(其密封 +0.1537 保持为子模型的确认锚);IRIS 自己的确认走 Step 0c 冻结的 EEGEyeNet 密封块单次开封。论文的信息账户章、证书结构、账本、措辞纪律全部继承——协方差膨胀门还让"认证"从经验性质升级为概率模型性质(证书变成可推导的)。clean-slate 设计文档的 S4(系统章)由 IRIS 重写,其余节保持。
