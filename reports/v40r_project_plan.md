# V40R project plan

V40R tests one narrow estimand: correct query-disjoint support minus the exact no-support route of
the same multichannel conditional diffusion checkpoint. It does not use deterministic superiority as
a gate. Work proceeds as R0 official audit; R1 official reproduction binding; R2 EEGDfus-MC
population training; R3 frozen-backbone support adaptation; R4 paired interventions; R5 natural
development evaluation; and R6 ablations, privacy, participant-first aggregation, tests, and delivery.

Hard stops are restricted to participant/support leakage, query-auxiliary inference access,
outer-test selection, nonfinite/scale failure, checkpoint mismatch, official-source modification, or
incorrect participant aggregation. V20–V39A, A-track, sealed data, and `taas_submission/**` remain
read-only.
